# Privacy Policy

Last Updated: June 28, 2026

This Privacy Policy explains how the Discord bot handles user information.

Information Collected

The bot may process:
- Discord User IDs
- Server IDs
- Channel IDs
- Role IDs
- Command usage
- Temporary data required for bot functionality

Data Usage

The collected information is used only to provide the bot's features and improve its functionality.

Data Sharing

The bot does not sell or share personal information with third parties unless required by law.

Data Storage

Only the minimum amount of data necessary for the bot's operation is stored.

Data Removal

Server administrators or users may request data deletion by contacting the developer.
